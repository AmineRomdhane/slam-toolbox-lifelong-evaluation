# SLAM Toolbox Lifelong Evaluation

Experimental framework for evaluating SLAM Toolbox 2.8.5 on ROS 2 Jazzy.

Initial objectives:
- Establish a reproducible static baseline
- Evaluate multiple predefined robot routes
- Record maps, serialized pose graphs, trajectories, timing, and resource usage
- Progressively introduce dynamic and structural environmental changes
- Characterize SLAM degradation and failure thresholds
